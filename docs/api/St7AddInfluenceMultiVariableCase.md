# St7AddInfluenceMultiVariableCase

Adds a new multi-variable load influence combination case.

long St7AddInfluenceMultiVariableCase(long uID, long MultiVariableType,
char* MultiVariableName)
Input Parameters
uID
Strand7 model file ID.
MultiVariableType
Either icInfluenceMin or icInfluenceMax.
MultiVariableName
Name of the load influence multi-variable combination case.
