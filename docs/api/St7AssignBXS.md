# St7AssignBXS

Assigns a BXS to the specified beam property.

Properties – Beams, Plates and Bricks

long St7AssignBXS(long uID, long PropNum, char* BXSName)

Input Parameters

uID

Strand7 model file ID.

PropNum

Beam property number.

BXSName

Full path and filename of the pre-existing .bxs file to assign to the property.
