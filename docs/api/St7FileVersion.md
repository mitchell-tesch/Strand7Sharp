# St7FileVersion

Returns the version of Strand7 used to save the specified file.

long St7FileVersion(char* FileName, long* Major, long* Minor, long* Point)
Input Parameters
FileName
Full path and filename for the Strand7 model.
Output Parameters
Major
Major version number A in the A.B.C format.
Minor
Minor version number B in the A.B.C format.
Point
Point version number C in the A.B.C format.
