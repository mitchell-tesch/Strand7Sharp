# St7AddFactorsEnvelope

Adds a new factors envelope to the specified model for the currently open solution.

long St7AddFactorsEnvelope(long uID, long EnvType, char* EnvName)

Input Parameters

uID

Strand7 model file ID.

EnvType

Factors envelope type; either etFactEnvelopeMin or etFactEnvelopeMax.

EnvName

Name of the envelope.
