# St7MergeLineOfBeams

Merges lines of beams.

long St7MergeLineOfBeams(long uID, double AngleTol, long AngleMode)

Input Parameters

uID

Strand7 model file ID.

AngleTol

Angular tolerance, above which beams will not be merged.

AngleMode

Either mbStatic or mbDynamic.

Dependencies
Selection

Beams can be selected using functions in Entity Selection.
