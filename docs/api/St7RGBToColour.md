# St7RGBToColour

Generates the Strand7 24-bit colour representation for a colour defined by its RGB components. See also RGB
Colours.

long St7RGBToColour(double Red, double Green, double Blue, long* Colour)

Input Parameters

Red

A value between 0.0 and 1.0 representing the red component of the colour.

Green

A value between 0.0 and 1.0 representing the green component of the colour.

Blue

A value between 0.0 and 1.0 representing the blue component of the colour.

Output Parameters

Colour

The 24-bit colour value as a long integer.
