# St7SetSolverLoadCaseCableInertia

Sets the load case that specifies the inertia loads applied to cable elements in the linear solvers.  The weight of the
cable defines the cable stiffness.

long St7SetSolverLoadCaseCableInertia(long uID, long CaseNum)

Input Parameters

uID

Strand7 model file ID.

Solver – General

CaseNum

Load case number.
