# St7InsertSRABaseCase

Inserts a new Base Excitation Spectral Response analysis case at the specified position.

long St7InsertSRABaseCase(long uID, long SRACase, char* CaseName)

Input Parameters

uID

Strand7 model file ID.

SRACase

Spectral Response base excitation case number.

CaseName

Spectral Response base excitation case name.
