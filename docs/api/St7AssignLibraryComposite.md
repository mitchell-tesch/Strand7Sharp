# St7AssignLibraryComposite

Assigns the specified item from the composite material library (.CML) to a ply property.

long St7AssignLibraryComposite(long uID, long PropNum, long LibraryID,

long ItemID)

Input Parameters

uID

Strand7 model file ID.

PropNum

Ply property number.

LibraryID

Library ID.

ItemID

Item ID.
