# St7AssignLibraryMaterial

Assigns the specified item from the material library (.MAT) to an entity property.

long St7AssignLibraryMaterial(long uID, long Entity, long PropNum,
long LibraryID, long ItemID)
Input Parameters
uID
Strand7 model file ID.
Entity
One of ptBEAMPROP, ptPLATEPROP or ptBRICKPROP.
PropNum
Element property number.
LibraryID
Library ID.
ItemID
Item ID.
