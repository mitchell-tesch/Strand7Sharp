# St7MergeElementPairs

Merges pairs of selected adjacent elements.

long St7MergeElementPairs(long uID, bool Quadratic)
Input Parameters
uID
Strand7 model file ID.
Quadratic
True to merge plate and brick pairs into quadratic elements.
False to merge plate and brick pairs into linear elements.
Dependencies
Selection
Elements can be selected using functions in Entity Selection.
