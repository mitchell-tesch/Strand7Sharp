# St7AssignLibraryCreepDefinition

Assigns the specified item from the creep definition library (.CRL) to a creep layout.

long St7AssignLibraryCreepDefinition(long uID, long CreepID, long LibraryID,

long ItemID)

Input Parameters

uID

Strand7 model file ID.

CreepID

Creep layout ID.

LibraryID

Library ID.

ItemID

Item ID.
