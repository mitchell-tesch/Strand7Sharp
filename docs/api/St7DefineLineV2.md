# St7DefineLineV2

Creates a new line definition based on two vertices.

long St7DefineLineV2(long uID, long VertexNum1, long VertexNum2, long* LineID)

Input Parameters

uID

Strand7 model file ID.

VertexNum1

Start vertex.

VertexNum2

End vertex.

Output Parameters

LineID

Line identifier.
