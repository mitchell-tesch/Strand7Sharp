# St7ClearResFileQuantity

Removes the specified result quantity from a given result case of the custom result file.

long St7ClearResFileQuantity(long uID, long CaseNum, long Entity, long Quantity)

Input Parameters

uID

Strand7 model file ID.

CaseNum

Result case number.

Custom Result Files

Entity

One of tyNODE, tyBEAM, tyPLATE or tyBRICK.

Quantity

Result quantity. See Custom Results for additional information.
