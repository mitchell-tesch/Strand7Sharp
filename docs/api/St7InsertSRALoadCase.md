# St7InsertSRALoadCase

Inserts a new blank Load Excitation case at the specified position within the Spectral Response analysis load
excitation table.

long St7InsertSRALoadCase(long uID, long SRACase, char* CaseName)
Input Parameters
uID
Strand7 model file ID.
SRACase
Spectral Response load excitation case number.
CaseName
Spectral Response load excitation case name.
