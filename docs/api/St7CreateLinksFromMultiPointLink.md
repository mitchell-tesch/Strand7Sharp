# St7CreateLinksFromMultiPointLink

Creates equivalent individual links from selected Rigid, Pinned and Master-Slave multi-point links.

long St7CreateLinksFromMultiPointLink(long uID, bool DeleteMPL)

Input Parameters

uID

Strand7 model file ID.

DeleteMPL

True to delete the source links.

Dependencies
Selection

Links can be selected using functions in Entity Selection.
