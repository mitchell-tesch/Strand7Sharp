# St7AddCombinationEnvelope

Adds a new combination envelope for the currently open solution.

long St7AddCombinationEnvelope(long uID, long EnvType, char* EnvName)

Input Parameters

uID

Strand7 model file ID.

EnvType

Combination envelope type; either etCombEnvelopeMin or etCombEnvelopeMax.

EnvName

Name of the envelope.
