# St7SetPlateCavityFluid

Assigns a cavity fluid layout to a surface of the specified plate.

long St7SetPlateCavityFluid(long uID, long PlateNum, long Surface, long CavityID)
Input Parameters
uID
Strand7 model file ID.
PlateNum
Plate number.
Surface
Local plate surface; either psPlateMinusZ or psPlatePlusZ.
CavityID
Cavity fluid layout ID.
